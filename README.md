# Moor Linux

Moor Linux is a custom Linux distribution project focused on creating a bootable installation ISO for a lightweight, configurable desktop/server environment.

This repository is the starting point for the project and will house the ISO build configuration, system customization, scripts, and release documentation.

## Project goals

- Build a reproducible Linux ISO image
- Keep the base system lightweight and easy to customize
- Provide clear setup and maintenance instructions
- Support future packaging, configuration, and release automation

## Repository status

This repo is currently being initialized. As the project grows, you can add:

- ISO build scripts
- OS configuration files
- Package or module definitions
- Documentation and release notes
- Generated artifacts and image output

## Getting started

1. Clone the repository
2. Review the project structure and documentation
3. Add or update configuration files needed for your ISO build
4. Run the build workflow or scripts for your target environment
